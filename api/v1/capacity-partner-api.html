Capacity Partner API

The Capacity Partner API: send outbound orders, track shipments, send inbound (receiving) orders and read inventory held in Capacity fulfillment centers. Documentation: https://partner-docs.capacityllc.com

Authentication​

  • HTTP: Bearer Auth

Get a token from POST /api/v1/auth/token (OAuth 2.0 client credentials) and send it as "Authorization: Bearer <token>". Tokens last about 15 minutes.

Security Scheme Type:

http

HTTP Authorization Scheme:

bearer

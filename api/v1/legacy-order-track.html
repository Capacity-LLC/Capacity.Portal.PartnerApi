POST

deprecated

New integrations must use POST /api/v1/outbound/orders/shipments; a new integration calling this path gets 410. Existing integrations keep sending the key body field (and apiversion, if they send it today); see Previous REST API paths.

Same request and response as Get shipment confirmations, where every field is described.

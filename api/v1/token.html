Get an access token

POST 
/api/v1/auth/token

Exchange your client ID and secret for a bearer token. Send it as Authorization: Bearer <token> on every other call. Tokens last about 15 minutes; expires_in in the response gives the exact number of seconds.

Form post, not JSON. Send grant_type=client_credentials with your client_id and client_secret, either as form fields or as an HTTP Basic Authorization header (client_id:client_secret, base64). If both are present, the header is used. Secrets are case-sensitive.

Reuse the token. It lasts about 15 minutes (expires_in, in seconds). Cache it and request a new one shortly before it expires; do not request a token per call.

Errors use the OAuth shape, not {"message": ...}: 400 {"error": "invalid_credentials", "error_description": ...}, 400 {"error": "unsupported_grant_type"}, and 503 {"error": "temporarily_unavailable", "error_description": ...} when the token service is briefly unavailable (retry with backoff).

Existing integrations. Integrations built against the previous Capacity REST API may keep calling POST /Token, at api-integration.capacityllc.com or api-partner.capacityllc.com, with the same request and response. New integrations must use this path; a new integration calling the previous path gets 410.

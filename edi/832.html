832 Product catalog (price/sales catalog)

The 832 creates and changes the products Capacity holds for you. Each LIN loop is one product. Send your catalog before the first 943 or 940 that uses a new item.

DirectionYou to Capacity
Version and GS01004010, SC
FolderIN in your folder
WhenEvery 10 minutes from 00:50 to 22:50; files that arrive later are picked up at 00:50, US Eastern
Answered byA 997 in the same run

The Envelopes page describes the ISA, GS, GE and IEA segments that wrap the file.

Key rules​

  • BCT10 says what to do with every product in the transaction set: 02 add, 04 change, 03 discontinue. Send 04 to create a product or update it.
  • LIN03 is the item's 12-digit UPC. Capacity uses it as the product's SKU.
  • Capacity reads the other LIN values by position, not by qualifier: LIN05 style, LIN07 colour, LIN09 size and so on, as listed below. Keep each value in its position. Send an empty qualifier and value pair for any value you skip.
  • The product name is built from the PID descriptions: style (08), colour (73) and size (74).
  • Send weight and volume in TD1. Kilograms and cubic centimetres are converted to pounds and cubic feet.
  • For a prepack, send LIN09 PPK and one SLN loop for each component item.
  • Segments that X12 allows but are not listed here are accepted and not used.

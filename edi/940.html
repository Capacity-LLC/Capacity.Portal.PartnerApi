940 Warehouse shipping order

The 940 tells Capacity to ship an order from your stock. Each transaction set (ST to SE) is one order. A file can carry many orders in one functional group.

DirectionYou to Capacity
Version and GS01004010, OW
FolderIN in your folder
WhenEvery 10 minutes from 00:50 to 22:50; files that arrive later are picked up at 00:50, US Eastern
Answered byA 997 in the same run, then a 945 when the order ships

The Envelopes page describes the ISA, GS, GE and IEA segments that wrap the file.

Key rules​

  • W0502 is your order number. It comes back in the 945 W0602.
  • W0505 is your pick ticket number. Use a new pick ticket for every order. Capacity holds an order that repeats an earlier one for review as a possible duplicate.
  • The 945 echoes your W0503 purchase order number (W0606), W0505 pick ticket (W0607) and W0504 link sequence number (W0608). Send these if you match shipments with them.
  • Send a ship-to N1 loop (N101 ST) with N3 and N4 on every order.
  • Send N9 CU with the retailer (customer) code agreed during onboarding. It tells Capacity which retailer's rules apply to the order.
  • Send one LX loop for each order line. W0105 identifies the item: use the UPC or SKU that Capacity holds for it.
  • For a prepack, send the prepack item with W0116 PPK. Capacity ships its components. Do not send component (SLN) lines on their own.
  • Capacity chooses lots when it picks, so a lot number in W0113 is not used.
  • Segments that X12 allows but are not listed here are accepted and not used.

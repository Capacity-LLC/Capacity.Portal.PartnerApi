997 Functional acknowledgment

A 997 says whether a functional group passed the X12 syntax check, and which transaction sets in it were accepted or rejected. It does not confirm business content: a shipment is confirmed by the 945, a receipt by the 944.

Version and GS01004010, FA
Capacity sendsOne 997 for every 940, 943 and 832 file, to OUT, in the same run that processes your file, normally within minutes
You may sendOne 997 for each 945 and 944 file, to IN or the folder agreed during onboarding. Optional

The Envelopes page describes the ISA, GS, GE and IEA segments that wrap the file.

997s Capacity sends​

Capacity acknowledges every group it receives. AK1 returns your GS01 and GS06. Each AK2 loop returns the ST01 and ST02 of one transaction set, and AK5 gives its result.

AK9 (group)MeaningWhat Capacity does
AAcceptedProcesses every transaction set.
EAccepted, errors notedProcesses the accepted sets. AK3 and AK4 describe the errors.
PPartially acceptedProcesses the sets with AK5 A or E. Sets with AK5 R are not processed.
RRejectedProcesses nothing from the group.

For a set with errors, AK3 names the segment and its position, and AK4 names the element, the error and the value received. Correct the rejected sets and send them again in a new file with new control numbers.

997s you send​

A 997 for a 945 or 944 is optional. If you send one, Capacity records whether each set was accepted.

  • Put AK101 SW for a 945 or RE for a 944, and the GS06 of Capacity's file in AK102.
  • Send one AK2 loop for each set, with its ST02 in AK202 and the result in AK501.
  • AK9 gives the result for the group.
  • Capacity reads AK1, AK2, AK5 and AK9. AK3 and AK4 are accepted and not used.

If you reject a 945 or 944, email itedi@capacityllc.com with the file name so that Capacity can correct and resend it.

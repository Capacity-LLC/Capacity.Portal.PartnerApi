Envelopes and control numbers

Every X12 file you exchange with Capacity is one interchange: an ISA header, one functional group (GS to GE) and an IEA trailer. Inside the group, each transaction set starts with ST and ends with SE.

Envelope structure
ISA  Interchange control header
  GS   Functional group header
    ST   Transaction set header
         ... segments of the set ...
    SE   Transaction set trailer
    (more ST to SE sets of the same type)
  GE   Functional group trailer
IEA  Interchange control trailer

Delimiters​

DelimiterCharacterNotes
Element separator*The character after ISA sets it
Component (sub-element) separator>ISA16
Segment terminator~The character after ISA16

Capacity reads the delimiters from the ISA of each file you send, so the characters above are recommended rather than required. A carriage return and line feed (CR LF) after each ~ is accepted.

Files Capacity sends always use *, > and ~, with CR LF after each ~, so each segment is on its own line. Capacity replaces any of these characters that appear inside a data value with a space.

Interchange IDs​

During onboarding you and Capacity agree each side's interchange ID qualifier (ISA05 and ISA07) and ID (ISA06 and ISA08). The examples in these guides use:

PartyQualifierID
You (example)ZZ Mutually definedPARTNEREXAMPLE
Capacity08 UCC EDI communications IDCAPACITY

GS02 and GS03 carry the same IDs, without the padding to 15 characters. In files Capacity sends, the IDs are reversed: Capacity is the sender.

ISA: interchange control header​

The ISA has a fixed width. Every element is padded to its full length, so the segment is always 106 characters including the terminator.

Control numbers​

  • ISA13 must be different for every interchange you send. Capacity also uses a new ISA13 for every interchange it sends.
  • GS06 must be different for every group. Capacity's 997 returns your GS06 in AK102, so a unique GS06 lets you match each 997 to its file.
  • ST02 must be unique within its group. The 997 returns it in AK202.
  • When you resend a corrected file, give it new control numbers.

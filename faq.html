Frequently asked questions

How do I get credentials?​

Email itedi@capacityllc.com. Ask for sandbox credentials to build and test, and for production credentials when you are ready to go live. See Environments.

Does submitting an order return an order ID?​

No. A successful submit returns {"accepted": true}. Refer to an order by your pick ticket (pickticketid), which must be unique per order.

How do I know an order has shipped?​

Poll shipment confirmations by batch. The Partner API has no webhooks or callbacks. See Send orders and track shipments.

Why is my order missing from batch 1?​

Batch 1 of a date covers confirmations created from 22:00 US Eastern the previous evening. A confirmation created at 22:30 on 2 November is in batch 1 of 3 November. See Dates and time zones.

What time zone are dates in?​

US Eastern (EST/EDT), with no offset in the value. See Dates and time zones.

My request timed out. Should I resend the orders?​

Not automatically: the orders may already have been accepted. Contact support with the time, the pick tickets and your X-Correlation-ID. See Retrying order submissions.

How long does an access token last?​

About 15 minutes (expires_in, in seconds). Reuse it, and get a new one shortly before it expires.

Are there rate limits?​

Not enforced today; follow the fair-use guidelines.

We already use the previous Capacity REST API. Do we need to change anything?​

No. Existing integrations keep working at api-integration.capacityllc.com with the same paths, requests and responses. To move to the current paths, follow Previous REST API paths. New integrations must use api-partner.capacityllc.com and the /api/v1/ paths.

Can I try requests without writing code?​

Yes: import the Postman collection, or use the OpenAPI document in your API tool of choice.

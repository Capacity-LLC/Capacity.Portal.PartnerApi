Connecting

Server and protocol​

Hostftp01.capacityllc.com
ProtocolsSFTP (SSH File Transfer Protocol), or FTPS (FTP over TLS)
LoginOne login per client, issued during onboarding. SFTP also accepts an SSH public key.
Your folderYou see only your own folder, named after your two-character owner code

Flat files and X12 EDI files use the same server and the same folders. Capacity does not exchange files over AS2 or through a value-added network (VAN).

Folders​

FolderWhat goes there
INOrder files and X12 files you send (940, 943, 832)
IN/NewSkusProduct upload files
IN/ReceivingOrderReceiving order files
OUT/ShipConfirmShip confirmation files
OUT/ReceivingConfirmReceiving confirmation files
OUT/InventoryInventory files
OUT/InventoryDeltaInventory adjustment files
OUTX12 files Capacity sends (945, 944, 997)

Capacity confirms the exact folders for your integration during onboarding.

Sending files​

  • Give every file a unique name. A timestamp in the name works well, for example orders-20261110-153000.txt.
  • Upload under a temporary name, then rename the file when the upload has finished, so that a half-written file is never picked up.
  • After a file is processed, Capacity moves it out of the inbound folder into an archive.
  • A file that cannot be read is moved to a BAD folder and reviewed by Capacity. Contact itedi@capacityllc.com if a file you sent has not been processed within the time below.

Collecting files​

  • Check your outbound folders on a schedule that suits you; the times below say when new files appear.
  • Download each file, then delete it or move it out of the folder. Capacity keeps its own copy.
  • File names are unique, so you never receive two different files with the same name.

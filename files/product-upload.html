Product upload file

The product upload file creates your products (SKUs) in Capacity and updates some of their details. Send it before the first order or receiving order that uses a new SKU. Each line describes one SKU.

DirectionYou to Capacity
FolderIN/NewSkus in your folder on ftp01.capacityllc.com
WhenEvery 30 minutes from 06:45 to 20:45 US Eastern, Monday to Saturday
What it doesCreates each SKU that does not exist yet, and updates the details a file can change for each SKU that does

The flat file rules apply: tab-delimited, a header row first, columns read by position. Send all 30 columns on every line, and no more.

SKU rules​

  • Each SKU must be unique within your account. A SKU may appear only once in a file.
  • Do not use spaces in a SKU. Capacity stores SKUs in upper case, so sku-example-1 and SKU-EXAMPLE-1 are the same SKU.
  • A SKU is locked once it is created. A line with a different SKU creates a new product; it never renames an existing one.
  • If the product has no UPC, repeat the SKU in the UPC column.

Units and values​

  • Weights are in pounds and dimensions in inches, for a full case.
  • CaseCube is the case volume in cubic feet: length × width × height in inches, divided by 1728. A 12 × 10 × 8 inch case is 0.5556 cubic feet.
  • Flag columns (TrackSerialNo, IsHazmat, TrackLotNumber, TrackExpiryDate) take 1 for yes and 0 for no.
  • CountryOfOrigin is the full country name, for example United States.
  • Prices and other decimals use a dot and no currency symbol or thousands separator.

Changing an existing SKU​

When a line names a SKU that already exists, the file updates these columns only: UPC, Brand, Category, RetailPrice, TrackSerialNo, CountryOfOrigin, HarmonizationCode, StyleNumber, ColorCode, SizeCode, NMFC, CommodityDesc, Class and the three availability columns.

The other columns are set when the SKU is created, and a later file does not change them:

  • Name
  • UOM, CaseQuantity and NoOfInnerPacks
  • CaseWeight, CaseLength, CaseWidth, CaseHeight and CaseCube
  • IsHazmat, TrackLotNumber, TrackExpiryDate and ShelfLifeInDays

To change any of these for an existing SKU, contact Capacity at itedi@capacityllc.com.

Rejected files and lines​

Capacity rejects the whole file when a whole-number column holds a decimal or text, a price holds a currency symbol, a UPC contains a dot, or a SKU appears twice. A line with an unknown UOM, or a SKU or Category longer than its maximum length, is rejected on its own.

A rejected file is moved to the BAD folder and reviewed by Capacity. Fix the file and send it again under a new name.

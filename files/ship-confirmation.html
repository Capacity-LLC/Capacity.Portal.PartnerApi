Ship confirmation file

The ship confirmation file tells you what shipped, how and when. Capacity writes one line per order line, with the order details repeated on every line.

DirectionCapacity to you
FolderOUT/ShipConfirm in your folder on ftp01.capacityllc.com
WhenEvery 4 hours from 02:00 to 22:00 US Eastern, with each order confirmed once. Some clients instead receive one file per day shortly after midnight US Eastern, as agreed at onboarding. No file is written when nothing shipped.
Which ordersOrders that reached Shipping status since the previous file. Orders placed through the Partner API are confirmed through the API instead.

How to read it​

  • Match each line to your order with PickTicketID, and to your order line with CapacityProductID or ItemProductID.
  • An order that ships in several cartons has one tracking number per carton in ShipTracking, separated by commas.
  • Pick up each file, then delete it or move it out of the folder. Capacity keeps a copy.

Versions​

Version 5.0 adds lot numbers and expiry dates to version 3.0. Version 4.0 adds return label details to version 3.0. Capacity confirms your version during onboarding.

38ExpiryDateChar2000NoExpiry dates shipped on the line, MM/DD/YYYY, separated by commas, in the same order as LotNo: the first expiry date belongs to the first lot. Empty for SKUs without expiry tracking.

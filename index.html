Capacity Partner API

Connect your order, inventory and receiving systems to Capacity fulfillment. Send orders, track shipments, send inbound stock and read inventory over a JSON API with OAuth 2.0 client credentials.

Get startedAPI referenceAuthentication

Your first call

Two requests: exchange your credentials for a token, then check the connection. The Quickstart goes on to submit a test order.

  • cURL
# 1. Get a token
curl -X POST "https://uat-api-partner.capacityllc.com/api/v1/auth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  --data-urlencode "grant_type=client_credentials" \
  --data-urlencode "client_id=$CAPACITY_CLIENT_ID" \
  --data-urlencode "client_secret=$CAPACITY_CLIENT_SECRET"

# 2. Test the connection
curl "https://uat-api-partner.capacityllc.com/api/v1/ping" -H "Authorization: Bearer $CAPACITY_TOKEN"
# "Connection is successful."

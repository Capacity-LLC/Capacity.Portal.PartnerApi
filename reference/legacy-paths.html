Previous REST API paths

Integrations built against the previous Capacity REST API keep working. They can call these paths with the same requests and responses at api-integration.capacityllc.com or api-partner.capacityllc.com. New integrations must use the /api/v1/ paths; a new integration that calls a previous path gets 410 Gone with the current path in the message.

Moving an existing integration​

  1. Change the base URL to https://api-partner.capacityllc.com and the token path to /api/v1/auth/token. Your credentials do not change.
  2. Change each path using the table above. Request and response bodies are the same, except for the two paths with no direct equivalent.
  3. Keep sending the key body field (and apiversion, if you send it today) until Capacity confirms your credentials are set up as a current integration; current integrations send neither.
  4. Test in the sandbox before switching production.
